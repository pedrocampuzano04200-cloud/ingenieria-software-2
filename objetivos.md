Objetivo general

Desarrollar un sistema de información web para la gestión de compras y
proveedores de la empresa Nexa Servicios, que permita centralizar la
información, controlar las diferentes etapas del proceso de compras y
garantizar la trazabilidad de las operaciones realizadas por los
usuarios.

Objetivos específicos

> 1\. Analizar el proceso actual de gestión de compras y proveedores de
> Nexa Servicios, identificando las actividades, responsables,
> necesidades, dificultades y puntos críticos que permitan establecer
> las funcionalidades requeridas para el sistema.
>
> 2\. Analizar el proceso actual de gestión de compras y proveedores de
> Nexa Servicios, identificando las actividades, responsables,
> necesidades, dificultades y puntos críticos que permitan establecer
> las funcionalidades requeridas para el sistema.
>
> 3\. Diseñar la arquitectura funcional y la estructura de información
> del sistema, utilizando modelos, casos de uso, diagramas y una base de
> datos que permitan representar adecuadamente el proceso de compras y
> la gestión de proveedores.
>
> 4\. Desarrollar una solución web que permita registrar, consultar,
> actualizar y gestionar la información relacionada con proveedores,
> solicitudes de compra, cotizaciones, órdenes de compra, recepción de
> productos o servicios, facturas y pagos, de acuerdo con los requisitos
> definidos.
>
> 5\. Validar el funcionamiento del sistema mediante pruebas que
> permitan comprobar el cumplimiento de los requisitos funcionales,
> reglas de negocio y requisitos no funcionales definidos para el
> proceso de compras y proveedores.
